フルバックアップ復元ツール

本体の「カード管理」タブで保存したフルバックアップ (mm-full-backup-v1 / v2) を読み込み、内容の確認と復元用 SQL の生成を行う単一ファイルツールです。v2 はクレジットカード (cc_cards / cc_tx) を含みます。ネットなしで動きます。

バックアップにはプレイヤーの暗証番号ハッシュが含まれます。ファイルの取り扱いに注意してください

1. バックアップファイルを読み込む

ここに JSON ファイルをドロップ
またはクリックしてファイルを選ぶ

2. 内容の確認

プレイヤーごとの残高（送金台帳から再計算）

3. 復元用 SQL を作る

前提: 新規 Supabase プロジェクトに schema.sql / schema_mm_trade.sql / schema_mm_invite.sql / schema_mm_void.sql / schema_mm_backup.sql / schema_cc.sql を適用済みで、対象テーブルが空であること。生成した SQL を新しいプロジェクトの SQL Editor に貼って実行すると復元されます。空でないテーブルに流すと主キー重複で失敗します。
