💱 めうまねー (MM) 台帳 引き継ぎツール

宝くじシステムの MM 台帳（ハッシュチェーン付き）を、ネットなしで検証・継続するための単一ファイルツールです。本体の「💱 MM」タブからエクスポートした JSON を読み込んで使います。

⚠ これは引き継ぎ用ツールです。複数人で同時に別々の台帳を延ばすと枝分かれします。運用は1人の担当者が引き継いでください

1. 台帳ファイルを読み込む

ここに JSON ファイルをドロップ
またはクリックしてファイルを選ぶ

2. チェーン検証と集計

自販機ごとの在庫

3. 記録を1件追加する

チェーンの続きに新しいレコードを付けます（連番とハッシュは自動で計算）。符号の約束: 発行（D→MM）は dia_delta がプラス / mm_delta がマイナス、還元（MM→D）はその逆、在庫操作は実際の増減、棚卸しは差分（実数 − 台帳の在庫）を増減として記録します。追加すると選んだ自販機の在庫にも反映されます。

4. 更新した台帳を保存する

同じ形式（mm-ledger-export-v1）で書き出します。次に使うときは、このファイルを読み込んでください。

記録の一覧（新しい順・直近30件）
